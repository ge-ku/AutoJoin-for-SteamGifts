# AutoJoin for SteamGifts
_Automatically enters giveaways from Steamgifts.com_

> **This extension will be unpublished soon.** SteamGifts 
> [announced](https://www.steamgifts.com/discussion/M9UFV/upcoming-autojoin-suspensions) 
> that users of the AutoJoin extension would be suspended starting June 1st. 
> The repository is kept public for reference. No further updates are planned.

AutoJoin for SteamGifts was a browser extension for Chrome and Firefox that automatically entered giveaways on [SteamGifts.com](https://www.steamgifts.com). Later, this functionality was disabled by default, but many other options were still available like infinite scrolling, quick joining and loading descriptions without opening a new page, night theme and filtering.

Now this repository features code with autojoin functionality removed. Browse the [last version with autojoin](https://github.com/ge-ku/AutoJoin-for-SteamGifts/tree/62c3f36ee9b41e3c40d682edb27936c17618e3e9) if you want to see how it worked.
